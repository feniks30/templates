# 01-landing-demo — шаблон интерактивного лендинга

Готовая заготовка одностраничного сайта/прототипа под ТЗ клиента.
Стек: чистый HTML/CSS/JS, без сборки и внешних зависимостей.

## Как запустить локально

1. Скопируйте папку `01-landing-demo` в рабочую папку заказа.
2. Откройте файл `index.html` в любом браузере (двойной клик или через «Открыть файл»).
3. Готово — сервер не нужен, все скрипты работают локально.

## Структура

- `index.html` — семантическая разметка: шапка, hero, услуги, тарифы, фильтруемый каталог, калькулятор, форма, футер, модальное окно.
- `style.css` — CSS-переменные, адаптивная сетка (Grid/Flexbox), нейтральная палитра с поддержкой тёмной темы через `prefers-color-scheme`.
- `app.js` — мок-данные, рендеринг карточек, фильтр каталога, калькулятор, валидация формы, модальное окно подтверждения без перезагрузки.
- `README.md` — этот файл.

## Быстрая адаптация под ТЗ клиента

1. **Текст и контент** — правьте `index.html`: заголовки, описания, подвал.
2. **Мок-данные** — в начале `app.js` массивы `SERVICES`, `TARIFFS`, `CATALOG` и объект `BASE_PRICES`. Редактируйте под услуги и цены клиента.
3. **Цвета и шрифты** — в `:root` в `style.css`: `--bg`, `--text`, `--accent`, `--radius` и т.д. Тёмная тема подхватывается из настроек ОС (`prefers-color-scheme`).
4. **Форма** — в `app.js` функция `validate()` и мок-отправка (таймаут 800 мс → модальное окно). При интеграции с бэкендом замените блок `await new Promise(...)` на `fetch` запрос.
5. **Калькулятор** — скорректируйте `BASE_PRICES` и шаги в `#calc-weeks`.

## Особенности

- Адаптив: шапка с гамбургер-меню, карточки перестраиваются в одну колонку на мобильных, калькулятор складывается вертикально.
- Валидация формы без перезагрузки страницы с показом ошибок под полями.
- Модальное окно подтверждения (overlay, ESC, клик по оверлею, кнопка «Ок»).
- Нет внешних библиотек, шрифтов и запросов к сети — работает офлайн.
