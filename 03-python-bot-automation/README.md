# 03-python-bot-automation — каркас Telegram-бота / парсера / автоматизации

Готовая заготовка на чистом Python 3.9+ без обязательных внешних библиотек.
Работа через `urllib.request` и long polling, настройки через `.env`, логирование,
экспорт данных в CSV/JSON, пример systemd-сервиса для VPS.

## Что внутри

- `main.py` — каркас бота/парсера: подключение к Telegram Bot API через `urllib.request`,
  long polling, обработка ошибок сети, логирование, экспорт в CSV/JSON, чтение `.env`.
- `.env.example` — шаблон переменных окружения (копируйте в `.env` и заполняйте).
- `deploy.sh` — пример systemd-сервиса для запуска на Linux VPS.

## Быстрый старт (локально)

```powershell
# 1. Копируйте шаблон в папку заказа
# 2. Создайте .env из примера
copy .env.example .env

# 3. Заполните .env: BOT_TOKEN, TARGET_URL, CHECK_INTERVAL

# 4. Запустите
python main.py
```

Бот запустится в режиме демо без реального токена: если `BOT_TOKEN` пустой,
работает только парсер/экспорт по `TARGET_URL` (если задан), иначе выводит
подсказку, куда вписать токен из BotFather.

## Запуск на VPS (Linux)

```bash
# На сервере
git clone <ваш-репозиторий>
cd 03-python-bot-automation
cp .env.example .env
nano .env   # впишите BOT_TOKEN и остальные параметры

# Установите systemd-сервис (смотрите deploy.sh)
sudo bash deploy.sh install
sudo systemctl start fh-bot
sudo systemctl status fh-bot
```

## Переменные окружения (.env)

| Переменная | Обязательна | Значение по умолчанию | Что это |
|------------|-------------|----------------------|---------|
| `BOT_TOKEN` | да* | — | Токен из BotFather (`123456789:AA...`). В чат и в репозиторий не присылать |
| `TARGET_URL` | нет | — | URL для парсинга (если бот используется как парсер) |
| `CHECK_INTERVAL` | нет | `60` | Интервал проверки в секундах |
| `EXPORT_FILE` | нет | `export.json` | Имя файла экспорта (JSON или CSV) |
| `EXPORT_FORMAT` | нет | `json` | `json` или `csv` |
| `LOG_LEVEL` | нет | `INFO` | `DEBUG`, `INFO`, `WARNING`, `ERROR` |

\* Обязателен только для режима Telegram-бота. Для чистого парсера можно не указывать.

## Экспорт данных

Бот сохраняет собранные записи в файл, указанный в `EXPORT_FILE`, в формате
`EXPORT_FORMAT` (`json` или `csv`). Экспорт выполняется при остановке бота
(`Ctrl+C`) и при сигнале завершения (SIGTERM).

## Безопасность

- `.env` с реальным токеном **не попадает в репозиторий** (см. `.gitignore`).
- Токен не выводится в логи.
- При коммите проверьте: `git grep -n "BOT_TOKEN" . ':!*.env.example'` — должно быть пусто.
