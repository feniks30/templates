# 02-crm-dashboard — шаблон панели учёта / админки

Готовая заготовка административной панели под ТЗ клиента.
Стек: чистый HTML/CSS/JS, без сборки и внешних зависимостей. Данные хранятся в `localStorage`.

## Как запустить локально

1. Скопируйте папку `02-crm-dashboard` в рабочую папку заказа.
2. Откройте файл `index.html` в любом браузере (двойной клик или «Открыть файл»).
3. Сервер не нужен — всё работает в браузере локально.

## Структура

- `index.html` — семантическая разметка: шапка, боковое меню, карточки метрик, панель поиска/фильтров, таблица записей, модальное окно добавления, кнопка экспорта.
- `style.css` — современный светлый интерфейс, CSS-переменные, адаптивная сетка, бейджи статусов, мобильная версия.
- `app.js` — мок-данные, `localStorage`, живой поиск, фильтрация, сортировка по колонкам, пересчёт метрик, экспорт в `export.csv` (UTF-8 с BOM для Excel).
- `README.md` — этот файл.

## Быстрая адаптация под ТЗ клиента

1. **Поля записей** — в начале `app.js` объект `FIELD_LABELS` и начальные `MOCK_RECORDS`. Добавьте/удалите поля под задачи клиента.
2. **Статусы** — массив `STATUSES` в `app.js` и соответствующие бейджи в `style.css` (классы `.badge-*`).
3. **Метрики** — функция `renderMetrics()` в `app.js`: Consider changed the counted statuses or add new cards.
4. **Цвета** — CSS-переменные в `:root` в `style.css` (`--bg`, `--text`, `--accent`, `--radius` и т.д.).
5. **Экспорт CSV** — функция `exportCSV()` в `app.js` формирует файл с UTF-8 BOM, чтобы Excel корректно отображал кириллицу. Колонки берутся из заголовков таблицы.

## Особенности

- Данные сохраняются в `localStorage` браузера — при перезагрузке страницы записи не теряются.
- Живой поиск по названию и сумме.
- Фильтр по статусу и по дате (от указанной даты).
- Сортировка по любой колонке таблицы при клике на заголовок.
- Модальное окно добавления записи с валидацией (без перезагрузки).
- Экспорт отфильтрованного набора записей в реальный `.csv` файл.
- Адаптив: на узких экранах таблица прокручивается горизонтально, боковое меню компактное.
- Нет внешних библиотек, шрифтов и сетевых запросов — работает офлайн.
