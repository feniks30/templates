# Служебные файлы: скопировать вручную

Файлы, имя которых начинается с точки (`.gitignore`, `.github/...`, `.env.example`), **не
загружаются** через браузерное «Upload files» — GitHub их просто не видит при перетаскивании папки.
Их создают руками: **Add file → Create new file**, в поле имени вставить путь целиком
(например `.github/workflows/tests.yml` — слэши создадут папки), вставить содержимое, Commit.

## 2. `.github/workflows/tests.yml` (проверка шаблонов на каждый push)

```yaml
# Проверка самих шаблонов: на публичном репозитории минуты Actions бесплатны и не ограничены.
name: templates

on:
  push:
    branches: [main]
  pull_request:
  workflow_dispatch:

permissions:
  contents: read

jobs:
  starter:
    name: starter
    runs-on: ubuntu-latest
    timeout-minutes: 5
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.13"
      - run: pip install --disable-pip-version-check -q pytest
      - name: Тесты базовки
        working-directory: starter
        run: pytest -q

  bot:
    name: bot-aiogram
    runs-on: ubuntu-latest
    timeout-minutes: 8
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.13"
      - name: Пакеты
        working-directory: bot-aiogram
        run: pip install --disable-pip-version-check -q -r requirements.txt
      - name: Тесты бота (без Telegram)
        working-directory: bot-aiogram
        run: pytest -q
      - name: Диалог в тренажёре
        working-directory: bot-aiogram
        run: python -m bot.simulate --script "Иван|нужен парсер цен конкурента|3 дня|Отправить"

  demo-page:
    name: demo-page
    runs-on: ubuntu-latest
    timeout-minutes: 5
    steps:
      - uses: actions/checkout@v4
      - name: Демо-страница без внешних ресурсов
        run: |
          f="demo-page/ДЕМО-СТРАНИЦА.html"
          test -f "$f" || { echo "::error::нет $f"; exit 1; }
          if grep -qE '<(script|link|img)[^>]+(src|href)="https?://' "$f"; then
            echo "::error::внешние ресурсы — страница должна открываться офлайн"; exit 1
          fi
          grep -q 'name="viewport"' "$f" || { echo "::error::нет meta viewport"; exit 1; }
          size=$(wc -c < "$f"); echo "вес: $size байт"
          [ "$size" -lt 122880 ] || { echo "::error::страница больше 120 КБ"; exit 1; }
          echo "демо-страница: чисто"
```

## Зачем это нужно

| Файл | Что даёт |
|---|---|
| `.gitignore` | `.venv`, `.env`, базы и логи не попадут в репозиторий |
| `.github/workflows/tests.yml` | на каждый push проверяются оба шаблона: `starter` (2 теста), `bot-aiogram` (58 тестов), демо-страница |
| `.env.example` | видно, какие переменные нужны боту, без чтения кода |

Один корневой `.gitignore` покрывает и вложенные папки — отдельные файлы в `starter/` и
`bot-aiogram/` не нужны.
