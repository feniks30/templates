# Переменные окружения бота

Файл `.env` рядом с папкой `bot/` — в репозиторий не попадает (он в `.gitignore`).
Шаблон для копирования — `bot-aiogram/.env.example` (если его нет в репозитории,
создайте файл `.env.example` в папке `bot-aiogram` и вставьте содержимое из
`docs/СЛУЖЕБНЫЕ-ФАЙЛЫ.md`).

| Переменная | Обязательна | Что это |
|---|---|---|
| `BOT_TOKEN` | да | токен из BotFather, вид `123456789:AA...`. В чат и в репозиторий не присылать |
| `DB_PATH` | нет | путь к SQLite, по умолчанию `data/requests.db` |
| `ALLOWED_IDS` | нет | id пользователей через запятую; пусто = демо открыто всем |
| `LIMIT_PER_MINUTE` | нет | лимит сообщений на пользователя, по умолчанию 8 |
| `WEBHOOK_BASE` | для `--webhook` | `https://домен/bots/orders` — Telegram принимает только https |
| `WEBHOOK_SECRET` | для `--webhook` | случайная строка 32 символа, проверяется в заголовке |
| `WEBHOOK_PORT` | нет | локальный порт aiohttp, по умолчанию 8081 |

Проверить, что токен не утёк:

```bash
git grep -nE "[0-9]{8,10}:[A-Za-z0-9_-]{30,}" -- . ':!*.md'
```

Пусто — чисто. Нашлось — отозвать токен у BotFather и выпустить новый.
