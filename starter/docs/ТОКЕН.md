# Ключи и доступы: {{NAME}}

Этот файл объясняет, **куда** вписывать секреты. Сами секреты здесь не хранятся.

## Правила

1. Секреты живут в `.env` локально и в переменных окружения на сервере. `.env` в `.gitignore`.
2. В переписке, в чатах с ИИ и в скриншотах секретов нет.
3. Токен демо-бота ≠ токен клиентского: клиент заводит свой и вписывает сам.

## Проверка перед сдачей

```bash
git grep -nE "sk-[A-Za-z0-9]|[0-9]{8,10}:[A-Za-z0-9_-]{30,}|password\s*=" -- . ':!*.md'
```

Пусто — значит чисто. Нашлось — вычистить и сменить ключ, история коммитов тоже хранит старое.

## Если ключ утёк

1. Отозвать ключ в панели (не «удалить файл»).
2. Выпустить новый.
3. Записать случай в `docs/ПЛАН.md` — чтобы через месяц не искать, почему перестало работать.
