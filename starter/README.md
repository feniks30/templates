## Что внутри

```
AGENTS.md            правила для ИИ-агента (Claude, Copilot, Codex): что читать и как коммитить
docs/ТЗ.md           что просит клиент, словами клиента
docs/ПЛАН.md         шаги до финиша с критериями «готово»
docs/СДАЧА.md        чек-лист приёмки: что показать и что передать
docs/ТОКЕН.md        куда вписывать ключи (и куда нельзя)
src/                 код
tests/               тесты: `python -m pytest -q` зелёный перед каждым коммитом
.github/workflows/   тесты на каждый push в main (GitHub Actions, Free-план)
```

## Начать

```bash
python -m venv .venv && . .venv/bin/activate
pip install -q pytest
python -m pytest -q            # 2 теста должны пройти
python src/main.py "проверка"  # печатает «проверка»
```

## Порядок работы

1. Заполнить `docs/ТЗ.md` — словами клиента, без своих догадок.
2. Разбить `docs/ПЛАН.md` на шаги по 1–3 часа, у каждого — критерий «готово».
3. Делать шаг → тест → коммит. Один шаг = один коммит.
4. Перед показом клиенту — `docs/СДАЧА.md`, глазами клиента: приватное окно и телефон.
5. Секреты только в `docs/ТОКЕН.md` локально и в переменные окружения на сервере.

## Если проект ведёт ИИ-агент

Начни сессию словами: «прочитай AGENTS.md, docs/ТЗ.md, docs/ПЛАН.md и сделай шаг 1».
Агент обязан остановиться на границе шага и не переписывать то, что уже работает.
